# 贪吃蛇 — 纯学习版设计

## 概述

极简版贪吃蛇游戏，使用纯 HTML + Canvas + JavaScript 单文件实现，作为新手练手项目。

## 核心功能

- **初始状态**：蛇长 3 节，出现在画布中央，初始方向向右
- **游戏循环**：每 150ms 移动一格
- **操控**：方向键改变移动方向（禁止 180° 掉头）
- **食物**：随机出现在空白格子里
- **吃食物**：蛇身增长 1 节，分数 +10
- **死亡判定**：蛇头撞墙或撞自身身体 → 游戏结束，显示 "Game Over"

## 技术规格

| 参数 | 值 |
|------|------|
| 画布 | 20×20 格子，每格 20px，总计 400×400px |
| 游戏循环 | `setInterval`，每 150ms 触发一次 tick |
| 蛇身存储 | 数组 `segments[]`，每节 `{x, y}` |
| 渲染 | 每 tick 清空画布，重新绘制蛇和食物 |
| 输入处理 | 键盘事件，缓存下一方向（防止连按导致 180° 掉头） |
| 碰撞检测 | 撞边 → 死；蛇头与身体某节坐标重合 → 死 |

## 文件结构

```
index.html   ← 单文件，包含 HTML + CSS + JavaScript
```

## 不包含范围

- 分数 UI、开始菜单、游戏结束交互界面
- 加速机制、障碍物、穿墙
- 音效、粒子效果
- 暂停/重新开始功能

## 验收标准

1. 打开 `index.html` 直接运行，无任何依赖
2. 方向键可控制蛇的移动方向
3. 蛇碰到食物后正确变长
4. 撞墙或撞自己后显示 "Game Over"
5. 代码行数控制在 100 行以内
